Algorithms: Introduction to Design

Program Development Cycle

  • Classic Model ("waterfall")
    • Feasibility
    • Requirements
    • Design
    • Implementation
    • Testing/QA
    • Deployment
    • Maintenance

Why Design Matters

  • Problems are solved in the design stage
    • Implementation can be very challenging (in a practical sense), but it is often considered to be secondary to design.
  • Not all designs are equally good
  • Great design → fast, efficient, user-friendly application

Algorithms

  • Definition: No single definition exists.
  • Common features of definitions:
    1. Finite set of steps or procedures
    2. Must be detailed (no skipping steps)
    3. Must lead to the solution
    4. Requires initial conditions to be met (or appropriate initial input provided)

Algorithm != Pseudocode

An algorithm is a general term for providing instructions. It is applicable to all kinds of situations (not just programming), and various formats can be used.

Pseudocode is a specific technique for describing an algorithm.
