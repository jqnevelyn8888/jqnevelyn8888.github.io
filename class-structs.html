A brief guide to creating your own C++ classes

Structs - a starting point

Before considering C++ classes, recall C structs. A C struct is kind of like your own custom variable type. A struct can consist of multiple different variable types. Some may be primitives (int, double, etc.); some may be more complex -- perhaps vectors or even other structs. Structs allow us to combine or unify all of these into a new variable type. A simple example is the Pixel struct that we encountered in an earlier lab: this struct combined three integers (RGB) because most people find it more convenient to think of images in terms of pixels rather than lists of numbers.

How is a C++ class different from a struct?

A class in C++ can be thought of as a more complex and powerful C struct. One can still create a single "container" for multiple different variable types using classes. However, in addition to containing properties (also known as fields), classes also contain methods. Methods are actions -- so unlike a struct, an object of some class-type can "do stuff". For example, a bank account object might be able to report its current balance via a method called getCurrentBalance(), allow for additional deposits via a method with a signature deposit(double amount), etc.

Simple example of a C++ class

Let us consider the following example problem:

Create a class called Textbook that represents a college textbook.

Your class should store:

  • The title
  • The edition number (a whole number)

Your class should be able to:

  • Display the title and edition number
  • Display a reminder by printing "Don't forget to check for a newer edition!"

In your main function:

  • Create a Textbook object with a title and edition of your choosing
  • Call the method to display its information
  • Call the method to display the reminder

The corresponding solution would look as follows:


#include <iostream>
#include <string>
using namespace std;

class Textbook {
public:
    string title; //these are the properties (fields) -- information that the object contains
    int edition;

    // the methods (actions) the object can take are defined below:
    void displayInfo() {
        cout << "Title: " << title << endl;
        cout << "Edition: " << edition << endl;
    }

    void displayReminder() {
        cout << "Don't forget to check for a newer edition!" << endl;
    }
};

int main() {
    Textbook t;
    t.title = "Introduction to Computer Science";
    t.edition = 3;

    t.displayInfo();
    t.displayReminder();

    return 0;
}

Note: the class defined above does not contain a constructor. This is ok for very simple objects, but for more complex programming problems, we will most likely need a constructor (and often, more than one). A constructor is a special-purpose method. We do not call it explicitly. Rather, it is invoked automatically when a new object of that class is created. Depending on the language/program, a new object is typically created via declaration of a variable of that class type or the use of the new keyword.

A more complex example: adding constructors

Let's consider a more complex problem that necessitates more complex objects:

Create a class called Notebook that represents a student's notebook.

Your class should store:

  • The subject (e.g., "Math")
  • The number of pages (a whole number)

Your class should have two constructors:

  • A default constructor that sets the subject to "General" and pages to 100
  • A parameterized constructor that accepts a subject and number of pages

Your class should be able to:

  • Display the subject and number of pages

In your main function:

  • Create one Notebook object using the default constructor
  • Create another using the parameterized constructor with values of your choosing
  • Display the information for both objects

Our solution might look as follows:


#include <iostream>
#include <string>
using namespace std;

class Notebook {
public:
    string subject;
    int pages;

    // Default constructor (informally, this just means "no inputs")
    Notebook() {
        subject = "General";
        pages = 100;
    }

    // Parameterized constructor (informally, this just means it has inputs)
    Notebook(string s, int p) {
        subject = s;
        pages = p;
    }

    void displayInfo() {
        cout << "Subject: " << subject << endl;
        cout << "Pages: " << pages << endl;
    }
};

int main() {
    Notebook n1;
    Notebook n2("Biology", 200);

    n1.displayInfo();
    cout << endl;
    n2.displayInfo();

    return 0;
}
