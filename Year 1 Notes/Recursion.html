Recursion

What is Recursion?

Formal definition: A method where the solution to a problem depends on the solutions to smaller instances of the same problem.

Informal definition: A function calling itself repeatedly while changing the input in order to reach some kind of stopping point/goal.

Iterative equivalence

Theoretical computer science includes a proof that recursive functions and iterative solutions are equivalent

Loops are usually more efficient than recursion.

  • Function calls are expensive in terms of system resource use (processor cycles and memory)

Compilers usually convert recursive code into "loop form"

Why recursion?

Recursive functions are often the best and easiest way for humans to solve a problem (at least initially)

Often the algorithm development process consist of two stages:

  1. Develop a recurive version
  2. Convert recursive to iterative

Three components of recursion

  • Base Case
    • Stopping point or goal
  • Work toward soluton
  • Recursive calls

Example


int factorial(int n) {
    if (n > 1) {
        return n * factorial(n-1);
    } else {
        return 1;
    }
}
