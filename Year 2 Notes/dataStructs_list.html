Data Structures - List Notes

List: Abstract Datatype

  • Public members
    • management → constructor, destructor
    • usage control → empty, size, clear
    • data access → insert, erase, push/pop front, front, push/pop back, back, operator []
  • Private members
    • implementation → data storage, support functions

List Implementation: Array

  • Static memory allocation (compile time)
    • 
                    const int Nmax = 10;
                    int data[Nmax];
  • Dynamic memory allocation (run time)
    • 
                    int Nmax = 10;
                    int *data = new int[Nmax];
                    ...
                    delete [] data;
  • Insert at back: pos = N
    • 
                    data[N++] = value;
  • Erase at back: pos = N-1
    • 
                    data[--N] = 0;
  • Insert in the middle: pos < N
    • 
                    for (int j = N; pos < j; j--) {
                        data[j] = data[j-1];
                    }
                    data[pos] = value;
                    N++;
  • Erase in the middle: pos < N-1
    • 
                    for (int j=pos; j < N-1; j++) {
                        data[j] = data[j+1];
                    }
                    data[N-1] = 0;
                    N--;
  • Resize
    • 
                    int M = Nmax + Nincr;
                    int *newdata = new int[M];

                    for (int i=0; i < M; i++) newdata[i] = data[i];
                    for (int i=N; i < M; i++) newdata[i] = 0;

                    delete [] data;
                    data = newdata;
                    Nmax = M;

List implementation: Single Linked

  • Sentinel head node, NULL terminated
    • 
                    struct node { int data; node *next; }
  • Sentinel node: dummy node (no data)
  • Sentinel value: data signaling termination
    • NULL character ending C-style string
    • NULL pointer ending single linked list
    • Data searched for (guarantees success)
  • Dynamic memory allocation
    • 
                    int N = 0;
                    node *head = new node;
                    
                    insert: new node, N++
                    erase: delete node, N--
                    relink list each time

                    delete head
  • Insert: pos = 0 ... N-1
    • 
                    1. node *p = new node;
                       p->data = value;
                       p->next = NULL;

                    2. node *pp = findnode(pos-1);

                    3. p->next = pp->next;
                       pp->next = p;
  • Erase: pos = 0 ... N-1
    • 
                    1. node *pp = findnode(pos-1);
                       node *p = pp->next;

                    2. pp->next = p->next;

                    3. delete p;

List Implementation: Double Linked

  • Sentinel head node, circular termination
    • 
                    struct node { int data; node *prev, *next; }
  • Insert: pos = 0 ... N-1
    • 
                    1. node *p = new node;
                       p-> data = value;
                       p->next = p->prev = this

                    2. node *pp = findnode(pos-1)

                    3. p->next = pp->next;
                       p->prev = pp;
                       p->next->prev = p;
                       p->prev->next = p;
  • Erase: pos = 0 ... N-1
    • 
                    1. node *p = findnode(pos);

                    2. p->prev->next = p->next;
                       p->next->prev = p->prev;

                    3. delete p;
