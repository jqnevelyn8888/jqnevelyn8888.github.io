String Streams

  • "Helper" Objects" for working with strings (which are also objects in C++)
  • Allow you to build or extract a string
  • Work similarly to other streams we've seen (file streams, I/O streams)
  • Can use stream manipulators like file streams and I/O streams
    • setw(), left, right, setfill(), etc
  • Use #include <sstream> to utilize
  • For stringstream, include <bits/stdc++.h>

Purpose

  • Input String Stream (istringstream)
    • Extract integers, doubles, and other data types from strings.
    • Uses a string as data source
  • Output String Stream (ostringstream)
    • Insert integers, doubles, and other data types into strings.
    • Builds a string

istringstream

  • Convenient way in C++ to extract data from a string. Consider the following example:
  • string data = "10 20.5 20"
    • This is a C++ string containing the following characters:
      • '1', '0', ' ', '2', '0', '.', '5', ' ', '3', '0'
    • How do I store 10, 20.5, and 30 as an individual integer, double, and another integer?

Re-using an istringstream

You must clear the istringstream flags prior to giving it another string.

            
                sin.clear();
                sin.str("Some Other Data")

.str() will be ignored if .clear() is not called. You must use .clear() FIRST and then call .str().

Use Cases: Getline

If we grab lines of input from cin and wish to store parts of that input as various data types, we can take the string created from getline() and pick it apart with a string stream.

  • #include <string>

Using the getline function, we can read an entire line from a stream. All characters up to (but not including) a '\n' are stored into a string variable.

  • getline(streamToReadFrom, stringToStore)

stringstream is bidirectional. You can build strings and extract from them.

Use Cases: Argv/Argc

  • When you have command line arguments that are numberical types (such as int, double, etc.), argv/argc store the data as a C-style string
  • In order to extract the data into the appropriate type, use an istringstream
