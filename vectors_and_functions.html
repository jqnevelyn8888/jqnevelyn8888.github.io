Modularity (Functions)

  • Organization, Readability
  • Problem solving process
  • Debugging
  • Resuability

Local variables: variables (including parameters) defined inside a function or block. Scope: visible only from the point of definition to the end of the nearest {}. Lifetime: created when execution reaches the definition, destroyed when the block ends. Scope ≠ lifetime: scope is compile-time visibility; lifetime is runtime existence. Isolation: local variables in different functions don’t interact, even with the same name. Order of destruction: locals are destroyed in reverse order of creation. Best practice: define variables as close as possible to first use. Parameters vs locals: parameters get values from the caller; locals are internal to the function. Temporaries: unnamed objects, no scope, destroyed at end of the expression.
