File Streams

A file stream is an object that allows your program to read data from a file or write data to a while, instead of using the keyboard and screen.

  • We can read and write from files very similarly to reading and writing to and from the console
  • This task is called working with file streams
  • ifstream = input file stream
  • ofstream = output file stream
  • fstream = can do both
  • #include <fstream>

Files

  • Files are data stored in "secondary storage"
    • Primary storage:
      • Random Access Memory (RAM)
      • Random isn't chaotic in this context, it means direct
    • Secondary storage:
      • Hard drive
      • USB drive
      • External hard drive
  • Volatile --> refers informally to whether or not stuff goes away when you unplug device
    • RAM is volatile.
    • Better work with primary storage than secondary storage

Steps to Use File Streams

Working with files in C++ requires the following steps:

  1. Include the <fstream> header file
  2. Declare a file variable (ifstream for reading input or ofstream for reading output) and name the variable (i.e. fin or fout)
  3. Open the file connecting the variable to the actual file and check for failure
  4. Do the work intended on the file (read or write) using << or >>
  5. Close the file

Declaring a File Stream Object


        ifstream infile;
        ofstream outfile;

.open()

Used to open BOTH input files for reading and to open output files for writing

  • Links a stream object with a file on your file system
  • Places a file reading marker at the beginning of the file, pointing to the first character in it.
  • If the input file doesn't exist, it won't be opened
  • If you don't have permission to open the input file, it won't be opened
  • If the output file does not exist, a new file with that name is created
  • If the output file already exists, it is erased (but there are ways to open files for appending content rather than overwriting)

Example


#include <fstream>
#include <iostream>
using namespace std;

int main(void) {
    ifstream fin;
    fin.open("myfile.txt");
    if (!fin.is_open()) {
        cout << "Could not open file\n";
    }

    string data;
    fin >> data;
    cout << "File contained: " << data << '\n';
    fin.close();

    return 0;
}

OUTPUT: File contained: Hello

.fail()

  • Returns false if the file was able to be opened
  • Returns true if it couldn't open the file
    • Doesn't exist
    • Don't have permission

is_open()

  • Returns true if the file is currently opened and linked to the file stream
  • Returns false if it couldn't open the file
    • Doesn't exist or doesn't have permission

.close()

  • de-links the file from the stream
  • ALWAYS close the file when you're done with it.
  • Every .open() should have a matching .close()
  • Closing a file you were writing to is equivalent to saving a file.

Extraction Operator >>

  • ifstream uses the extraction operator exactly like cin

#include <fstream>
#include <iostream>

using namespace std;

int main() {
    ifstream fin;
    int a, b, c;
    fin.open("myfile2.txt");
    fin >> a >> b >> c;
    cout << "I got three integers: " << a << " " << b << " " << c << endl;
    fin.close();

    return 0;
}

OUTPUT: I got three integers: 1 2 3

Line Oriented Input

  • fin >> will skip preceding whitespace and extract until the next whitespace.
  • Instead, you can grab one line at a time with getline()
  • getline(fin, line)
    • getline returns:
      • true - if it was able to get a line and put it into line
      • false - if it was not
    • getline will grab a line and put it into a string line

ifstream fin;
string line;
fin.open("myfile.txt");
while (getline(fin, line)) {
    cout << "Line = " << line << '\n';
fin.close()
}

OUTPUT: (not include the bullet points)

  • Line = Hello World
  • Line = I am
  • Line = Evelyn Sama

Output File Streams

ofstream acts just like cout except it writes to a file, not the console.

  • Can even add formatting manipulators we encountered earlier (from iomanip)

Output: 

Senti was really frustrated
Because Fu Hua was treating her like a child
Senti wants to prove to Fu Hua she isn't a child.
Fu Hua is                         500000 years old while Senti is about 6 years old.
                

#include <fstream>
#include <iostream>
#include <iomanip>

using namespace std;

int main(void) {

    ofstream outfile("SentiHua.txt");

    outfile << "Senti was really frustrated\n";
    outfile << "Because Fu Hua was treating her like a child\n";
    outfile << "Senti wants to prove to Fu Hua she isn't a child. \n";
    outfile << "Fu Hua is " << setw(30) << 500000 << " years old while Senti is about 6 years old.";

    outfile.close();

    ifstream infile("SentiHua.txt");
    string line;
    while (getline(infile, line)) {
        cout << line <<'\n';
    }
    infile.close();

    return 0;
}
