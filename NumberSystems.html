Number Systems

What is a Positional Number System?

  • A way to represent a number and its magnitude using the "position" a digit a placed.
  • Base determines the power base.
    • Decimal 10p
    • Binary 2p
    • Hexadecimal 16p
    • Octal 8p
  • Place starts with power 0
  • Base determines available symbols. The number of symbols is the base. Avaiable symbols (digits) are typically represented by 0 through (base - 1). Past "9", we typically use letters starting with A.
    • Decimal: 0-9
    • Binary: 0-1
    • Hexadecimal: 0-F
    • Octal: 0-7

Decimal (Base 10)

The weight of each digit of a decimal number depends on its relative position within the number.

  • (Ex.) Decoding of the baae-10 number 1234
  • 1234:
    • 1*1000 + 2*100 + 3*10 + 4*1
  • Decimal consists of powers of 10
    • 1000(103), 100(102), 10(101), 1(100)
  • For each ascending place, its magnitude grows 10x

Fractions: Descending place, its magnitude is divided by 10.

  • 27.212 = 2(10) + 7(1) + 2(10-1) + 1(10-2) + 2(10-3)

Binary (Base 2)

A digit in binary(0 or 1) is also called a bit. Only these two digits are used in binary.

Like a decimal number, the "weight" of each binary digit in a binary number depends on its relative position.

For each ascending place, magnitude grows 2x.

  • (ex.) 1101
    • 1*8 + 1*4 + 0*2 + 1*1
  • Binary consists of powers of 2
    • 1*(23) + 1*(22) + 0*(22) + 1*(20)
  • For each ascending place, its magnitude grows 2x
