BitOps

Class Notes

  • Word = group of bits > 8
    • 16, 32, 64
  • 'Mask' = binary string that gives us answers

Bitwise Operators

  • CPUs only allow us to manipulate BYTES, not BITS
  • Cannot directly manipulate bits
  • Use bitwise to manipulate bits
Note: 8 bits in a byte

Logical AND (&) Operator

  • Logical AND is a binary operator. Is signed agnostic.
  • Algorithm: line up bits. Where the column has two 1s, the result is 1. Otherwise, it is 0.
    0b0110_0110
  & 0b0100_0100
  _____________
    0b0100_0100

Logical OR | Operator

  • Logical OR is a binary operator. Is signed agonistic.
  • Algorithm: line up bits. Where a column has at least a 1, the result is 1. Otherwise, it is 0.
    0b0110_0110
  | 0b0100_0101
  _____________
    0b0110_0111

Logical NOT ~ Operator

  • Logical NOT is a unary operator. Is signed agnostic. Also called "one's complement"
  • Algorithm: flip all 0s to 1s and all 1s to 0s.
    ~0b0110_0110 = 0b1001_1001

Logical XOR ^ Operator

  • Logical XOR (exclusive OR) is a binary operator. Is signed agnostic.
  • Algorithm: line up bits. Where the column has exactly one 1, the result is 1. Otherwise, it is 0.
    0b0110_0110
  ^ 0b0100_0101
  _____________
    0b0010_0011

Logical LSHIFT << Operator

  • Logical LSHIFT (left shift) is a binary operator. Is signed agnostic.
  • value << number_of_shifts
    • bits that fall off the left are discarded
    • 0s are added from the right
    • Mathematically: value * 2number_of_shifts
    0b0100_1001 << 2 = 0b0010_0100

Logical RSHIFT >> Operator

  • Logical RSHIFT (right shift) is a binary operator. Is signed agnostic.
  • unsigned_value >> number of shifts
    • Bits that fall off the right are discarded
    • 0s are added from the left
    • Mathematically: unsigned_value/2number of shifts
    0b0100_1001 >> 2 = 0b0001_0010

Arithmetic RSHIFT >> Operator

  • Difference between Arithmetic RSHIFT and logical RSHIFT:
    • Logical shift fills with 0s, arithmetic shift copies the sign bit to keep the number positive or negative
  • signed_value >> number of_shifts
    • Bits that fall off the right are discarded
    • The sign bit is added to the left
    0b1100_1001 >> 2 = 0b1111_0010

Clarification - Signed bit

  • In a signed binary number, the leftmost bit is called the signed bit
    • 0 --> Positive number
    • 1 --> Negative number

XOR Invertibility

  • XOR is an inversion of itself. Used in cryptography for "stream ciphers."
  • Exclusive or, only returns true when bits are DIFFERENT
      0b0110_0011
    ^ 0b0111_0110
    _____________
      0b0001_0101
    ^ 0b0111_0110
    _____________
      0b0110_0011

Bit Shift Example


#include <iostream>
#include <cstdint>
#include <bitset>

using namespace std;

int main(void) {
    uint8_t a = 8, b = 7;
    cout << "a is " << (int) a << '\n';
    cout << "b is " << (int) b << '\n';

    cout << "a >> 1 is " << (a >> 1) << '\n';
    cout << "b >> 1 is " << (b >> 1) << '\n';

    cout << "a << 1 is " << (a << 1) << '\n';
    cout << "b << 1 is " << ((b << 1)) << '\n';

    bitset<8> c = 0b0000'0001;
    c = c << 3;
    cout << "c << 3: " << c << '\n';

    return 0;
}
Output: 

a is 8
b is 7
a >> 1 is 4
b >> 1 is 3
a << 1 is 16
b << 1 is 14
c << 3: 00001000
